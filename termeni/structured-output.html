Structured output

Ieșire structurată
intermediar

Răspuns într-un format formal, de exemplu JSON validat prin schemă, în locul textului liber. Reduce ambiguitatea între model și cod și permite verificare automată.

DE CE CONTEAZĂUn rezultat JSON poate trece validarea sintactică și totuși conține un preț sau o dată inventată. Schema verifică forma datelor; valoarea lor trebuie confirmată separat.
Termeni înrudiți: JSON · JSON Schema · Function calling Apel de funcție · Output contract Contract de ieșire
Apare în scenariul: Rezultatul corect ca formă, greșit ca valoare
