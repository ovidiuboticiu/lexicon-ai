Agent2Agent (A2A)
avansat

Agent2Agent (A2A) este un protocol deschis de interoperabilitate între agenți AI. Permite descoperirea capabilităților prin Agent Card și schimbul de mesaje, sarcini și rezultate între aplicații agentice diferite.

DE CE CONTEAZĂUn agent poate delega o sarcină unui alt agent implementat pe o platformă diferită, fără ca cele două sisteme să folosească același model sau framework.
Termeni înrudiți: MCP · Multi-agent Sistem multi-agent · Handoff Predare între agenți sau etape
