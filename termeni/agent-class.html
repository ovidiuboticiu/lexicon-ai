Agent class

Clasă de agenți
avansatsens descriptiv

Categorie de responsabilități și reguli comune pentru agenți, de exemplu cercetare, dezvoltare sau asigurarea calității (QA). Este o noțiune de proiectare: nu presupune neapărat o clasă Python și poate cuprinde mai multe configurații sau instanțe.

DE CE CONTEAZĂTrei agenți de cercetare pot folosi aceeași regulă pentru citarea surselor, dar sarcini și contexte diferite. O clasă comună ajută la compararea rezultatelor; instanțele pot avea și alte configurații distincte.
