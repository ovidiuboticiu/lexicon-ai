Skill

Capabilitate modulară
intermediar

Capabilitate reutilizabilă a unui agent pentru o categorie de sarcini, definită, după platformă, prin instrucțiuni, resurse, scripturi sau instrumente. Termenul nu are aceeași implementare în toate ecosistemele. De exemplu, specificația Agent Skills descrie un director care conține un fișier obligatoriu SKILL.md și poate include scripturi ori documentație.

DE CE CONTEAZĂO capabilitate poate fi reutilizată între sarcini, dar forma de instalare, condițiile de activare și permisiunile depind de platformă; numele „skill” nu garantează un comportament standard.
Termeni înrudiți: Tool Unealtă · Agent contract Contract de agent · Prompt
