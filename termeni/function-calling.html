Function calling

Apel de funcție
intermediar

Mecanism prin care modelul produce o cerere structurată către o funcție. Modelul propune apelul; codul din jur îl validează și îl execută.

DE CE CONTEAZĂDacă modelul cere ștergerea unui fișier printr-un apel structurat, aplicația trebuie să verifice permisiunea și calea înainte de execuție; structura JSON singură nu oferă siguranță.
