ReAct
intermediar

Vezi „Buclă ReAct”. Denumire pentru alternarea dintre raționament/decizie, acțiune și observație.

DE CE CONTEAZĂDacă o căutare nu returnează rezultate, un agent ReAct poate folosi observația pentru a reformula cererea. Un plan fix poate include și el verificări; avantajul tiparului ReAct este integrarea explicită a feedbackului în pașii următori, cu limite de reluare.
