Open-weight model

Model cu ponderi deschise
de bazănou

Model ale cărui ponderi (valorile învățate la antrenare) sunt publicate și pot fi descărcate, astfel încât modelul poate fi rulat pe un calculator sau server propriu care are resursele necesare, în condițiile licenței. Nu înseamnă automat „open source”: datele și codul de antrenare pot rămâne nepublicate, iar licența poate impune restricții.

DE CE CONTEAZĂPermite folosirea locală, fără trimiterea datelor la un serviciu extern, și control asupra versiunii folosite. Licența trebuie citită: unele restricționează anumite utilizări sau impun condiții pentru folosirea comercială.
EXEMPLUUn model descărcat și rulat cu Ollama sau LM Studio pe propriul laptop.
