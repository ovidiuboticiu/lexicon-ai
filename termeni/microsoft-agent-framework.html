Microsoft Agent Framework

Framework Microsoft pentru agenți
intermediarprodus / instrument

Framework open-source pentru dezvoltarea agenților AI și a fluxurilor de lucru care combină modele, instrumente, stare și componente software. Reunește idei din AutoGen și Semantic Kernel și oferă mecanisme de orchestrare și observabilitate.

DE CE CONTEAZĂ Este util pentru aplicații în care trebuie urmărite execuții cu mai mulți pași și integrate controale de sistem. Nu trebuie confundat cu AutoGen ori cu un serviciu de găzduire: este un framework de dezvoltare.
Termeni înrudiți: OpenAI Agents SDK SDK OpenAI pentru agenți · Google Agent Development Kit (ADK) Kit Google pentru agenți AI · Orchestration Orchestrare
