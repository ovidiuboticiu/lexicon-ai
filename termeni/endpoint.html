Endpoint
intermediar

Vezi „API · endpoint · token de acces”. Este un punct de acces la un serviciu sau API, identificat de obicei printr-o adresă, prin care pot fi accesate una sau mai multe operații.

DE CE CONTEAZĂUn endpoint greșit poate direcționa cereri sau date către serviciul nepotrivit; adresa și autentificarea trebuie controlate.
Termeni înrudiți: API · endpoint · access token API · endpoint · token de acces · Local endpoint Endpoint local · Webhook
