API key

Cheie API
de bazănou

Un șir de caractere prin care un serviciu recunoaște aplicația sau proiectul din care vin cererile trimise prin API și, după caz, permite anumite operații. Cheile secrete, folosite de multe servicii AI, se păstrează ca parolele: cine obține o astfel de cheie poate face cereri în limitele permisiunilor ei și poate genera costuri în contul asociat. Unele servicii au și chei publice, pentru utilizări limitate.

DE CE CONTEAZĂO cheie secretă publicată din greșeală, de exemplu într-un fișier pus pe internet sau într-o captură de ecran, poate fi folosită de alții pe banii tăi. Cheile secrete se păstrează separat de cod și se dau doar programelor care au nevoie de ele. Dacă o cheie a fost expusă, o revoci din contul serviciului și pui una nouă în locul ei.
EXEMPLUConectezi un serviciu AI la un instrument de automatizare. Serviciul îți generează o cheie API secretă, pe care o lipești în setările instrumentului. Dacă trimiți cuiva o captură în care cheia se vede întreagă, ai trimis și cheia.
