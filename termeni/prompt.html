Prompt

Prompt
de bază

Conținutul trimis modelului ca intrare pentru un apel: instrucțiuni, mesaje, exemple și, în sisteme multimodale, imagini ori audio. Delimitarea dintre prompt și context depinde de API și de convenția folosită.

DE CE CONTEAZĂInstrucțiunea „nu șterge fișiere” poate reduce propunerile nedorite, dar interdicția trebuie aplicată și prin permisiunile efective ale instrumentului folosit de agent.
EXEMPLU„Rezumă acest articol în trei propoziții, pentru un elev de liceu”, împreună cu textul articolului: acesta este promptul.
CUM LE DEOSEBEȘTIPrompt · Instrucțiuni de sistem
  • Dacă scrii o cerere sau trimiți un document de prelucrat → aceasta este partea ta din prompt.
  • Dacă aplicația transmite reguli separat, prin canalul de sistem → sunt instrucțiuni de sistem; ajung și ele la model ca parte a intrării, dar au alt rol: stabilesc regulile, iar aplicația le poate da prioritate.
