Context injection

Injecție de context
intermediar

Introducerea deliberată a informației externe în contextul modelului. Poate fi statică, din documente fixe, sau dinamică, de exemplu prin RAG.

DE CE CONTEAZĂIntroducerea controlată de documente sau date în context poate îmbunătăți răspunsurile. Nu trebuie confundată cu prompt injection, care urmărește deturnarea instrucțiunilor.
Termeni înrudiți: Prompt injection Injecție malițioasă de prompt · Trust boundary Graniță de încredere · Context engineering Ingineria contextului
Apare în scenariul: Documentul care dă ordine agentului
