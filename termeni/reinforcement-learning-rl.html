Reinforcement learning (RL)

Învățare prin întărire
intermediar

Paradigmă în care un agent învață o politică de alegere a acțiunilor din interacțiuni cu un mediu și din semnale de recompensă, urmărind de regulă maximizarea recompensei cumulative așteptate. Include problema explorării versus exploatării. Nu orice agent AI este antrenat prin învățare prin întărire.

DE CE CONTEAZĂÎntr-un simulator, un agent poate învăța să evite acțiuni care aduc recompense imediate, dar pierderi mai mari ulterior. Acest mecanism este diferit de simpla executare a unei liste de instrucțiuni.
