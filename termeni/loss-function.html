Loss function

Funcție de pierdere
de bazănou

Formula care măsoară cât de departe este modelul de obiectivul stabilit. În învățarea supravegheată, compară de obicei predicția cu răspunsul-țintă. În timpul antrenării, scopul este ca această valoare să scadă.

DE CE CONTEAZĂAntrenarea urmărește reducerea a ceea ce măsoară funcția de pierdere, nu neapărat ce își doresc oamenii în general. Dacă măsura este prost aleasă, modelul poate deveni foarte bun la lucrul greșit.
EXEMPLUDacă modelul estimează prețul unui apartament la 90.000 de euro, iar prețul real este 100.000, funcția de pierdere transformă diferența într-un număr care arată cât de mare a fost greșeala.
