API · endpoint · token de acces
intermediar

API este interfața prin care două programe comunică; endpoint-ul este punctul de acces, de obicei o adresă, prin care sunt accesate una sau mai multe operații; tokenul de acces autentifică sau autorizează cererea. Tokenul de acces nu este același lucru cu tokenul de text al unui LLM.
