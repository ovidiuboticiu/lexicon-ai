Overfitting to the benchmark

Supraînvățare pe benchmark
intermediar

Ajustarea repetată a sistemului după rezultatele unui benchmark cunoscut, până când scorul pe acel set crește fără o îmbunătățire corespunzătoare pe cazuri noi. Un set înghețat nu previne problema dacă rezultatele sale influențează dezvoltarea; evaluarea finală trebuie făcută pe date independente, protejate de procesul de ajustare.

DE CE CONTEAZĂUn scor bun pe un set public poate rezulta din ajustări repetate după rezultate. Testul final trebuie protejat de aceste ajustări, nu doar păstrat neschimbat.
