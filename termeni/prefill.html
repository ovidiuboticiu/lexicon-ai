Prefill

Procesarea inițială a promptului
avansat

Faza de procesare a tokenilor de intrare înainte de generarea răspunsului. Într-o buclă agentică, întregul context poate necesita reprocesare la fiecare apel dacă nu există reutilizare de prefix (prefix caching); nu este recitit integral la fiecare token generat.

DE CE CONTEAZĂÎn cereri lungi, prefill-ul influențează timpul până la primul răspuns și consumul de resurse, separat de generarea tokenilor.
Termeni înrudiți: Decode · token generation Decodare · generare de tokeni · Time to First Token (TTFT) Timp până la primul token · Prefix caching Reutilizarea prefixului
