intermediar

Operație aleasă sau executată de agent în cadrul sarcinii: citire, căutare, apel API, scriere de fișier, comandă ori răspuns. Unele acțiuni doar observă, iar altele modifică mediul; modificările externe sunt efecte secundare (side effects).

DE CE CONTEAZĂCitirea unui document și ștergerea lui sunt ambele acțiuni, dar cer permisiuni și verificări diferite. Nu orice acțiune produce o modificare externă.
Termeni înrudiți: Observation Observație · Tool call Apel de unealtă · Side effect Efect secundar extern · Agent loop Buclă agentică
