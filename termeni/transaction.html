Transaction

Tranzacție
intermediar

Într-un sistem tranzacțional, de exemplu o bază de date, grup de operații tratate ca o unitate atomică, conform garanțiilor oferite de acel sistem. O tranzacție a bazei de date nu acoperă automat emailuri, plăți sau apeluri API externe.

DE CE CONTEAZĂDacă emailul a fost trimis, dar modificarea din baza de date eșuează, anularea tranzacției SQL (rollback) nu retrage mesajul deja trimis; pentru acestea trebuie proiectată recuperarea sau compensarea.
