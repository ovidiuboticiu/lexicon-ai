Held-out · frozen evaluation

Date rezervate · evaluare înghețată
avansat

Held-out desemnează date sau sarcini rezervate față de antrenare și ajustare, pentru o evaluare independentă. Frozen înseamnă că versiunea setului, regulile sau procedura sunt fixate; un set înghețat nu devine automat independent dacă a fost consultat în dezvoltare.

DE CE CONTEAZĂUn benchmark fix poate fi supraînvățat prin ajustări repetate după rezultate. Independența setului și fixarea protocolului trebuie verificate separat.
Termeni înrudiți: Data contamination Contaminarea datelor de evaluare · Protocol freeze Înghețarea protocolului · Training / validation / test split Separarea seturilor de antrenare, validare și test
