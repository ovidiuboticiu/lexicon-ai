Failure mode

Mod de eșec
intermediar

Tip recurent de comportament prin care sistemul nu își atinge obiectivul: unealtă greșită, stare inconsistentă, plan incomplet, halucinație, retry infinit, permisiune lipsă etc.

DE CE CONTEAZĂClasificarea modurilor de eșec permite măsuri țintite; o singură rată globală de succes le poate ascunde.
Termeni înrudiți: Failure propagation Propagarea eșecului · Recovery Recuperare după eșec · Red teaming Testare adversarială · Fault injection Injectare controlată de defecte
