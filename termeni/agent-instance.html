Agent instance

Instanță de agent
avansat

Activare concretă a unei configurații de agent pentru o sarcină. Două instanțe pot folosi același model și reguli de bază, dar au identificatori, context și stare proprii; eventual și spații de lucru separate.

DE CE CONTEAZĂDouă instanțe ale aceluiași agent pot avea sarcini și utilizatori diferiți. Dacă istoricul sau permisiunile unei instanțe ajung în cealaltă, apare o problemă de izolare, chiar dacă modelul folosit este identic.
